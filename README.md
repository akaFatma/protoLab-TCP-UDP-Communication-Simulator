# ProtoLab: TCP/UDP Network Simulator 🌐



A visual simulator for understanding TCP and UDP protocol communication through real-time network packet visualization.

## Features 

- **Real-Time Simulation**: Visualize TCP/UDP packet transmission between nodes
- **Interactive Network Diagram**: Drag-and-drop nodes with D3.js-powered visualization
- **Protocol Inspection**: View detailed packet headers (sequence numbers, ACKs, ports)
- **Error Simulation**: Introduce packet loss and observe protocol behavior
- **Connection Logging**: Track handshakes (SYN, SYN-ACK, ACK) and termination (FIN)
- **Statistics Dashboard**: Monitor bandwidth usage and packet success rates

## Technologies 

- **Frontend**: JavaScript, HTML5, CSS3, [D3.js](https://d3js.org/)
- **Backend**: Node.js, [Socket.IO](https://socket.io/)
- **Build Tools**: npm, Webpack
- **Visualization**: SVG animations, Canvas rendering
